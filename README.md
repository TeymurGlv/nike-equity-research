# Nike, Inc. (NKE) – Equity Research Initiation

**Rating: HOLD | 12-month target price: $34 | Price at pricing date (17 Nov 2026): $36.25**

📄 [Read the full report (PDF)](Nike%20Initiation%20Report.pdf) · 📊 [Valuation model (Excel)](Nike%20Valuation%20Model.xlsx)

## Thesis
- At $36.25 the market already prices a ~12% FY31 operating margin, the bottom of management's 12–14% target.
- Reaching 13% requires operating overhead at ~21.7% of revenue, below every year since FY22 (23.2–24.6%), using ~90% of the $2.5bn Pace savings before reinvestment.
- Base case: ~11% margin, value $32.65. Bull +6%, Bear −32%: an asymmetric risk/reward.

## What would change the view
FY29 operating overhead at or below 24.0% of revenue, with demand creation at 10% or more → move to Buy.

## Method
Normalized FY22–FY26 financials from 10-K filings · driver-based forecast to FY31 · Bull/Base/Bear scenarios · DCF with value-driver terminal value · reverse DCF · trading comparables.
